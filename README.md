# AttendPro LCD Edition 📋

**Android attendance app — Personal + Company use**

AttendPro LCD Edition is a clean, professional attendance manager with a bright LCD-style interface.

## ✨ Features
- Personal + Company attendance in one app
- Live clock with TOTAL HOURS hero display
- Employee management with search
- Colour-coded day ticks — Present / Absent / Half Day / Weekly Off / Leave
- Auto hours calculation (Out − In − Break) + overtime tracking
- Monthly calendar view & reports with salary estimates
- Export reports as CSV / Excel / PDF
- Admin & Employee roles with optional PIN
- JSON Backup & Restore
